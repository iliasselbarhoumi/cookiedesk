CookieDesk adalah editor cookie untuk pengembang, penguji, dan siapa saja yang ingin melihat apa yang disimpan sebuah situs. Lihat cookie, edit cookie, tambah dan hapus cookie, serta cari cookie, di popup atau panel samping. Anda yang memilih.

YANG MEMBEDAKANNYA

• Editor cookie berpartisi. Chrome menyembunyikan cookie berpartisi (CHIPS) dari alat yang tidak memintanya, sehingga editor cookie lain diam-diam menampilkan daftar yang tidak lengkap. CookieDesk menampilkannya di samping cookie biasa, masing-masing diberi label partisinya.
• Urungkan di setiap perubahan. Edit, hapus, impor, dan pemulihan set ditulis ke jurnal urungkan terlebih dahulu, lalu diperiksa. Jika Chrome menolak suatu perubahan, semuanya dikembalikan dan Anda diberi tahu alasannya. Satu klik mengembalikan cookie persis seperti semula selama 10 menit; pada kasus langka ketika salinan urungkan tidak bisa disimpan, CookieDesk bertanya sebelum melanjutkan.
• Editor cookie tanpa iklan, tanpa pelacakan, dan tanpa permintaan jaringan. Sumber terbuka, jadi Anda bisa memeriksa setiap barisnya.
• Izin per situs. Saat dipasang, tidak ada permintaan “membaca dan mengubah semua data Anda di semua situs web”. Anda mengizinkan CookieDesk satu situs per satu, melihat setiap situs yang Anda izinkan, dan menghapus izin mana pun dengan satu klik.

LIHAT COOKIE

• Penampil cookie untuk setiap cookie situs saat ini: nama, nilai, domain, path, dan masa berlaku, dengan lencana untuk cookie HttpOnly, Secure, SameSite, sesi, dan berpartisi.
• Cookie HttpOnly ditandai jelas “tidak terlihat oleh JavaScript halaman”.
• Pencarian sungguhan: filter menurut nama, nilai, atau domain saat Anda mengetik, bahkan dengan seratus cookie.
• Tampilan langsung: lihat cookie mana yang disetel atau diubah situs saat Anda menggunakannya.
• “Fungsi cookie ini”: setiap flag dijelaskan dengan kata-kata sederhana, termasuk apakah nilainya JSON Web Token dan kapan token itu kedaluwarsa.

EDIT COOKIE

• Edit cookie HttpOnly dan setiap kolom lainnya: nama, nilai, domain, path, masa berlaku, Secure, HttpOnly, SameSite, dan partisi.
• Kesalahan tertangkap sebelum dilihat Chrome. SameSite=None tanpa Secure, cookie __Host- di subdomain, masa berlaku yang sudah lewat: aturannya dijelaskan di samping kolomnya.
• Nilai panjang seperti JWT tidak pernah merusak tata letak; salin nilai apa pun dengan satu tombol.
• Lindungi cookie penting agar hapus massal, impor, dan pemulihan set tidak menyentuhnya.

HAPUS COOKIE

• Hapus satu cookie, atau setiap cookie yang ditampilkan pencarian, setelah melihat daftar persis apa yang akan hilang. Bisa diurungkan selama 10 menit.

MANAJER COOKIE UNTUK ALUR KERJA NYATA

• Set cookie: simpan cookie sebuah situs sebagai file bernama (misalnya “masuk sebagai admin”) dan pulihkan nanti. CookieDesk menunjukkan apa yang akan berubah sebelum melakukan apa pun, dan tidak menyimpan salinan sendiri.
• Bandingkan: lihat apa yang diubah oleh proses login (cookie mana yang ditambahkan, dihapus, atau berubah) antara set tersimpan dan kondisi sekarang, atau antara dua set.
• Salin cookie antara jendela normal dan jendela penyamaran Anda (setelah Anda mengaktifkan “Izinkan dalam mode Samaran” untuk CookieDesk).
• Impor dan ekspor JSON atau Netscape cookies.txt, atau salin cookie sebagai kode document.cookie. Ekspor memperingatkan bahwa file berisi cookie sesi aktif dan harus diperlakukan seperti kata sandi.
• Mengutamakan keyboard: / untuk mencari, tombol panah untuk berpindah, Enter untuk mengedit, c untuk menyalin, p untuk melindungi, Del untuk menghapus, Ctrl+Z untuk mengurungkan, ? untuk daftar lengkap.

PRIVASI

CookieDesk tidak mengumpulkan apa pun dan tidak mengirim apa pun ke mana pun. Tanpa analitik, tanpa akun, tanpa sinkronisasi, tanpa kode jarak jauh. CookieDesk sendiri tidak menyimpan nilai cookie di disk: salinan urungkan ada di memori dan hilang saat Chrome ditutup. (Cookie yang Anda salin ke penyimpanan normal disimpan oleh Chrome, seperti cookie lain di sana.) Setelan dan jumlah penggunaan disimpan secara lokal. Kode sumbernya terbuka untuk umum di bawah lisensi MIT.
