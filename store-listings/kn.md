CookieDesk ಡೆವಲಪರ್‌ಗಳು, ಟೆಸ್ಟರ್‌ಗಳು ಮತ್ತು ವೆಬ್‌ಸೈಟ್ ಏನನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ ಎಂದು ನೋಡಲು ಬಯಸುವ ಯಾರಿಗಾದರೂ ಕುಕೀ ಎಡಿಟರ್. ಕುಕೀಗಳನ್ನು ನೋಡಿ, ಕುಕೀಗಳನ್ನು ಎಡಿಟ್ ಮಾಡಿ, ಕುಕೀಗಳನ್ನು ಸೇರಿಸಿ, ಅಳಿಸಿ ಮತ್ತು ಹುಡುಕಿ, ಪಾಪ್‌ಅಪ್‌ನಲ್ಲಿ ಅಥವಾ ಸೈಡ್ ಪ್ಯಾನೆಲ್‌ನಲ್ಲಿ. ಯಾವುದನ್ನು ಬಳಸಬೇಕು ಎಂಬುದು ನಿಮ್ಮ ಆಯ್ಕೆ.

ಇದನ್ನು ಭಿನ್ನವಾಗಿಸುವುದು ಏನು

• ಪಾರ್ಟಿಷನ್ಡ್ ಕುಕೀ ಎಡಿಟರ್. ಕೇಳದ ಟೂಲ್‌ಗಳಿಂದ Chrome ಪಾರ್ಟಿಷನ್ಡ್ (CHIPS) ಕುಕೀಗಳನ್ನು ಅಡಗಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಇತರ ಕುಕೀ ಎಡಿಟರ್‌ಗಳು ಮೌನವಾಗಿ ಅಪೂರ್ಣ ಪಟ್ಟಿಯನ್ನು ತೋರಿಸುತ್ತವೆ. CookieDesk ಅವನ್ನು ಸಾಮಾನ್ಯ ಕುಕೀಗಳ ಪಕ್ಕದಲ್ಲೇ, ಪ್ರತಿಯೊಂದರ ಪಾರ್ಟಿಷನ್ ಲೇಬಲ್‌ನೊಂದಿಗೆ ತೋರಿಸುತ್ತದೆ.
• ಪ್ರತಿ ಬದಲಾವಣೆಗೂ ರದ್ದುಮಾಡುವ ಸೌಲಭ್ಯ. ಎಡಿಟ್‌ಗಳು, ಅಳಿಸುವಿಕೆಗಳು, ಆಮದುಗಳು ಮತ್ತು ಸೆಟ್ ಮರುಸ್ಥಾಪನೆಗಳನ್ನು ಮೊದಲು ರದ್ದು ಜರ್ನಲ್‌ನಲ್ಲಿ ಬರೆಯಲಾಗಿ ನಂತರ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ. Chrome ಯಾವುದೇ ಬದಲಾವಣೆಯನ್ನು ನಿರಾಕರಿಸಿದರೆ ಎಲ್ಲವೂ ಹಿಂದಕ್ಕೆ ಹೋಗುತ್ತದೆ, ಕಾರಣವನ್ನೂ ತಿಳಿಸಲಾಗುತ್ತದೆ. 10 ನಿಮಿಷಗಳವರೆಗೆ ಒಂದೇ ಕ್ಲಿಕ್‌ನಲ್ಲಿ ಕುಕೀ ಇದ್ದಂತೆಯೇ ಮರಳುತ್ತದೆ; ಅಪರೂಪಕ್ಕೆ ರದ್ದು ಪ್ರತಿಯನ್ನು ಇಡಲಾಗದಿದ್ದರೆ, ಮುಂದುವರಿಯುವ ಮೊದಲು CookieDesk ಕೇಳುತ್ತದೆ.
• ಜಾಹೀರಾತು, ಟ್ರ್ಯಾಕಿಂಗ್ ಮತ್ತು ನೆಟ್‌ವರ್ಕ್ ವಿನಂತಿಗಳಿಲ್ಲದ ಕುಕೀ ಎಡಿಟರ್. ಓಪನ್ ಸೋರ್ಸ್, ಆದ್ದರಿಂದ ಪ್ರತಿ ಸಾಲನ್ನೂ ನೀವೇ ಪರಿಶೀಲಿಸಬಹುದು.
• ಸೈಟ್ ಪ್ರಕಾರ ಅನುಮತಿ. ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡುವಾಗ "ಎಲ್ಲಾ ವೆಬ್‌ಸೈಟ್‌ಗಳಲ್ಲಿ ನಿಮ್ಮ ಎಲ್ಲಾ ಡೇಟಾವನ್ನು ಓದಿ ಮತ್ತು ಬದಲಾಯಿಸಿ" ಎಂಬ ಪ್ರಾಂಪ್ಟ್ ಬರುವುದಿಲ್ಲ. CookieDesk ಅನ್ನು ಒಮ್ಮೆಗೆ ಒಂದು ಸೈಟ್‌ಗೆ ಅನುಮತಿಸುತ್ತೀರಿ, ಅನುಮತಿಸಿದ ಪ್ರತಿ ಸೈಟ್ ಅನ್ನು ನೋಡುತ್ತೀರಿ, ಯಾವುದನ್ನಾದರೂ ಒಂದೇ ಕ್ಲಿಕ್‌ನಲ್ಲಿ ತೆಗೆಯುತ್ತೀರಿ.

ಕುಕೀಗಳನ್ನು ನೋಡಿ

• ಪ್ರಸ್ತುತ ಸೈಟ್‌ನ ಪ್ರತಿ ಕುಕೀಗೆ ಕುಕೀ ವೀಕ್ಷಕ: ಹೆಸರು, ಮೌಲ್ಯ, ಡೊಮೇನ್, ಪಾತ್ ಮತ್ತು ಅವಧಿ ಮುಕ್ತಾಯ, ಜೊತೆಗೆ HttpOnly, Secure, SameSite, ಸೆಷನ್ ಮತ್ತು ಪಾರ್ಟಿಷನ್ಡ್ ಕುಕೀಗಳ ಬ್ಯಾಡ್ಜ್‌ಗಳು.
• HttpOnly ಕುಕೀಗಳನ್ನು "ಪುಟದ JavaScript ಗೆ ಕಾಣಿಸುವುದಿಲ್ಲ" ಎಂದು ಸ್ಪಷ್ಟವಾಗಿ ಗುರುತಿಸಲಾಗುತ್ತದೆ.
• ನಿಜವಾದ ಹುಡುಕಾಟ: ನೂರು ಕುಕೀಗಳಿದ್ದರೂ, ಟೈಪ್ ಮಾಡುತ್ತಿದ್ದಂತೆ ಹೆಸರು, ಮೌಲ್ಯ ಅಥವಾ ಡೊಮೇನ್ ಮೂಲಕ ಫಿಲ್ಟರ್ ಮಾಡಿ.
• ಲೈವ್ ವೀಕ್ಷಣೆ: ನೀವು ಸೈಟ್ ಬಳಸುವಾಗ ಅದು ಯಾವ ಕುಕೀಗಳನ್ನು ಹೊಂದಿಸುತ್ತದೆ ಅಥವಾ ಬದಲಾಯಿಸುತ್ತದೆ ಎಂದು ನೋಡಿ.
• "ಈ ಕುಕೀ ಏನು ಮಾಡುತ್ತದೆ": ಪ್ರತಿ ಫ್ಲ್ಯಾಗ್ ಅನ್ನು ಸರಳ ಮಾತುಗಳಲ್ಲಿ ವಿವರಿಸಲಾಗುತ್ತದೆ, ಮೌಲ್ಯ JSON Web Token ಹೌದೇ ಅಲ್ಲವೇ ಮತ್ತು ಆ ಟೋಕನ್ ಯಾವಾಗ ಮುಗಿಯುತ್ತದೆ ಎಂಬುದನ್ನೂ ಒಳಗೊಂಡು.

ಕುಕೀಗಳನ್ನು ಎಡಿಟ್ ಮಾಡಿ

• HttpOnly ಕುಕೀಗಳನ್ನು ಮತ್ತು ಇತರ ಪ್ರತಿ ಕ್ಷೇತ್ರವನ್ನು ಎಡಿಟ್ ಮಾಡಿ: ಹೆಸರು, ಮೌಲ್ಯ, ಡೊಮೇನ್, ಪಾತ್, ಅವಧಿ ಮುಕ್ತಾಯ, Secure, HttpOnly, SameSite ಮತ್ತು ಪಾರ್ಟಿಷನ್.
• ತಪ್ಪುಗಳು Chrome ನೋಡುವ ಮೊದಲೇ ಸಿಕ್ಕಿಬೀಳುತ್ತವೆ. Secure ಇಲ್ಲದ SameSite=None, ಉಪಡೊಮೇನ್‌ನಲ್ಲಿ __Host- ಕುಕೀ, ಹಿಂದಿನ ಅವಧಿ ಮುಕ್ತಾಯ: ನಿಯಮವನ್ನು ಕ್ಷೇತ್ರದ ಪಕ್ಕದಲ್ಲೇ ವಿವರಿಸಲಾಗುತ್ತದೆ.
• JWT ಗಳಂತಹ ಉದ್ದದ ಮೌಲ್ಯಗಳು ಲೇಔಟ್ ಅನ್ನು ಎಂದಿಗೂ ಹಾಳುಮಾಡುವುದಿಲ್ಲ; ಯಾವುದೇ ಮೌಲ್ಯವನ್ನು ಒಂದು ಕೀಲಿಯಿಂದ ನಕಲಿಸಿ.
• ಮುಖ್ಯ ಕುಕೀಗಳನ್ನು ರಕ್ಷಿಸಿ, ಆಗ ಬಲ್ಕ್ ಅಳಿಸುವಿಕೆ, ಆಮದು ಮತ್ತು ಸೆಟ್ ಮರುಸ್ಥಾಪನೆ ಅವನ್ನು ಮುಟ್ಟುವುದಿಲ್ಲ.

ಕುಕೀಗಳನ್ನು ಅಳಿಸಿ

• ಒಂದು ಕುಕೀಯನ್ನು, ಅಥವಾ ಹುಡುಕಾಟ ತೋರಿಸುವ ಪ್ರತಿ ಕುಕೀಯನ್ನು, ಏನೇನು ಹೋಗುತ್ತದೆ ಎಂಬ ನಿಖರ ಪಟ್ಟಿ ನೋಡಿದ ನಂತರ ಅಳಿಸಿ. 10 ನಿಮಿಷಗಳವರೆಗೆ ರದ್ದುಮಾಡಬಹುದು.

ನಿಜವಾದ ಕೆಲಸಕ್ಕಾಗಿ ಕುಕೀ ಮ್ಯಾನೇಜರ್

• ಕುಕೀ ಸೆಟ್‌ಗಳು: ಸೈಟ್‌ನ ಕುಕೀಗಳನ್ನು ಹೆಸರಿಟ್ಟ ಫೈಲ್ ಆಗಿ ಉಳಿಸಿ ("ಅಡ್ಮಿನ್ ಆಗಿ ಲಾಗಿನ್ ಆದದ್ದು" ನಂತೆ) ಮತ್ತು ನಂತರ ಮರುಸ್ಥಾಪಿಸಿ. ಏನನ್ನಾದರೂ ಮಾಡುವ ಮೊದಲು ಏನು ಬದಲಾಗುತ್ತದೆ ಎಂದು CookieDesk ತೋರಿಸುತ್ತದೆ, ತಾನು ಯಾವುದೇ ಪ್ರತಿಯನ್ನು ಇಟ್ಟುಕೊಳ್ಳುವುದಿಲ್ಲ.
• ಹೋಲಿಸಿ: ಲಾಗಿನ್ ಆದಾಗ ಏನಾಯಿತು (ಯಾವ ಕುಕೀಗಳು ಸೇರಿದವು, ತೆಗೆಯಲ್ಪಟ್ಟವು ಅಥವಾ ಬದಲಾದವು) ಎಂಬುದನ್ನು ಉಳಿಸಿದ ಸೆಟ್ ಮತ್ತು ಈಗಿನ ಸ್ಥಿತಿಯ ನಡುವೆ, ಅಥವಾ ಎರಡು ಸೆಟ್‌ಗಳ ನಡುವೆ ನೋಡಿ.
• ನಿಮ್ಮ ಸಾಮಾನ್ಯ ಮತ್ತು ಇನ್‌ಕಾಗ್ನಿಟೊ ವಿಂಡೋಗಳ ನಡುವೆ ಕುಕೀಗಳನ್ನು ನಕಲಿಸಿ (CookieDesk ಗೆ "ಇನ್‌ಕಾಗ್ನಿಟೊದಲ್ಲಿ ಅನುಮತಿಸಿ" ಆನ್ ಮಾಡಿದ ನಂತರ).
• JSON ಅಥವಾ Netscape cookies.txt ಆಮದು ಮತ್ತು ರಫ್ತು ಮಾಡಿ, ಅಥವಾ ಕುಕೀಗಳನ್ನು document.cookie ಸ್ನಿಪ್ಪೆಟ್ ಆಗಿ ನಕಲಿಸಿ. ಫೈಲ್‌ನಲ್ಲಿ ಚಾಲ್ತಿಯಲ್ಲಿರುವ ಸೆಷನ್ ಕುಕೀಗಳಿವೆ, ಅದನ್ನು ಪಾಸ್‌ವರ್ಡ್‌ನಂತೆ ಪರಿಗಣಿಸಬೇಕು ಎಂದು ರಫ್ತುಗಳು ಎಚ್ಚರಿಸುತ್ತವೆ.
• ಕೀಬೋರ್ಡ್-ಮೊದಲು: ಹುಡುಕಲು /, ಚಲಿಸಲು ಬಾಣಗಳು, ಎಡಿಟ್‌ಗೆ Enter, ನಕಲಿಸಲು c, ರಕ್ಷಿಸಲು p, ಅಳಿಸಲು Del, ರದ್ದುಮಾಡಲು Ctrl+Z, ಪೂರ್ಣ ಪಟ್ಟಿಗೆ ?.

ಗೌಪ್ಯತೆ

CookieDesk ಏನನ್ನೂ ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ ಮತ್ತು ಎಲ್ಲಿಗೂ ಏನನ್ನೂ ಕಳುಹಿಸುವುದಿಲ್ಲ. ಅನಲಿಟಿಕ್ಸ್ ಇಲ್ಲ, ಖಾತೆಗಳಿಲ್ಲ, ಸಿಂಕ್ ಇಲ್ಲ, ರಿಮೋಟ್ ಕೋಡ್ ಇಲ್ಲ. CookieDesk ತಾನಾಗಿ ಡಿಸ್ಕ್‌ನಲ್ಲಿ ಕುಕೀ ಮೌಲ್ಯಗಳನ್ನು ಇಡುವುದಿಲ್ಲ: ರದ್ದು ಪ್ರತಿಗಳು ಮೆಮೊರಿಯಲ್ಲಿರುತ್ತವೆ, Chrome ಮುಚ್ಚಿದಾಗ ಹೋಗುತ್ತವೆ. (ನಿಮ್ಮ ಸಾಮಾನ್ಯ ಸ್ಟೋರ್‌ಗೆ ನೀವು ನಕಲಿಸುವ ಕುಕೀಗಳನ್ನು, ಅಲ್ಲಿನ ಯಾವುದೇ ಕುಕೀಯಂತೆ, Chrome ಉಳಿಸುತ್ತದೆ.) ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ಬಳಕೆಯ ಲೆಕ್ಕಗಳನ್ನು ಸ್ಥಳೀಯವಾಗಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. ಸೋರ್ಸ್ ಕೋಡ್ MIT ಪರವಾನಗಿಯಡಿ ಸಾರ್ವಜನಿಕವಾಗಿದೆ.
