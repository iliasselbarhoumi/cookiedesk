• പാർട്ടീഷൻഡ് കുക്കി എഡിറ്റർ. ചോദിക്കാത്ത ടൂളുകളിൽ നിന്ന് Chrome പാർട്ടീഷൻഡ് (CHIPS) കുക്കികളെ മറയ്ക്കുന്നു, അതുകൊണ്ട് മറ്റ് കുക്കി എഡിറ്റർമാർ നിശ്ശബ്ദമായി അപൂർണ്ണമായ പട്ടിക കാണിക്കുന്നു. CookieDesk അവയെ സാധാരണ കുക്കികൾക്ക് അടുത്തായി, ഓരോന്നിനും അതിന്റെ പാർട്ടീഷൻ ലേബലോടെ കാണിക്കുന്നു.

Chrome ഏതെങ്കിലും മാറ്റം നിരസിച്ചാൽ എല്ലാം തിരികെ പോകും, കാരണവും അറിയിക്കും. 10 മിനിറ്റ് വരെ ഒരു ക്ലിക്കിൽ കുക്കി പഴയതുപോലെ തിരിച്ചെത്തും; അപൂർവമായി പഴയപടിയാക്കാനുള്ള പകർപ്പ് സൂക്ഷിക്കാനായില്ലെങ്കിൽ, തുടരുന്നതിന് മുമ്പ് CookieDesk ചോദിക്കും.
• പരസ്യങ്ങളോ ട്രാക്കിങ്ങോ നെറ്റ്‌വർക്ക് അഭ്യർത്ഥനകളോ ഇല്ലാത്ത കുക്കി എഡിറ്റർ. ഓപ്പൺ സോഴ്സ്, അതിനാൽ ഓരോ വരിയും നിങ്ങൾക്ക് തന്നെ പരിശോധിക്കാം.

കുക്കികൾ കാണുക

• നിലവിലെ സൈറ്റിലെ എല്ലാ കുക്കികൾക്കുമുള്ള കുക്കി വ്യൂവർ: പേര്, മൂല്യം, ഡൊമെയ്ൻ, പാത്ത്, കാലഹരണം, കൂടാതെ HttpOnly, Secure, SameSite, സെഷൻ, പാർട്ടീഷൻഡ് കുക്കികൾക്കുള്ള ബാഡ്ജുകൾ.
• HttpOnly കുക്കികൾ "പേജിലെ JavaScript-ന് കാണാനാവില്ല" എന്ന് വ്യക്തമായി അടയാളപ്പെടുത്തും.
• ശരിയായ തിരയൽ: നൂറ് കുക്കികളുണ്ടെങ്കിലും, ടൈപ്പ് ചെയ്യുന്നതിനൊപ്പം പേര്, മൂല്യം, ഡൊമെയ്ൻ പ്രകാരം ഫിൽട്ടർ ചെയ്യാം.
• ലൈവ് വ്യൂ: നിങ്ങൾ സൈറ്റ് ഉപയോഗിക്കുമ്പോൾ അത് ഏതൊക്കെ കുക്കികൾ സജ്ജമാക്കുന്നു അല്ലെങ്കിൽ മാറ്റുന്നു എന്ന് കാണുക.
• "ഈ കുക്കി എന്താണ് ചെയ്യുന്നത്": ഓരോ ഫ്ലാഗും ലളിതമായ വാക്കുകളിൽ വിശദീകരിക്കുന്നു, മൂല്യം JSON Web Token ആണോ എന്നും ആ ടോക്കൺ എപ്പോൾ കാലഹരണപ്പെടുമെന്നും ഉൾപ്പെടെ.

കുക്കികൾ എഡിറ്റ് ചെയ്യുക

• HttpOnly കുക്കികളും മറ്റ് എല്ലാ ഫീൽഡുകളും എഡിറ്റ് ചെയ്യാം: പേര്, മൂല്യം, ഡൊമെയ്ൻ, പാത്ത്, കാലഹരണം, Secure, HttpOnly, SameSite, പാർട്ടീഷൻ.
• തെറ്റുകൾ Chrome കാണുന്നതിന് മുമ്പേ പിടിക്കപ്പെടും. Secure ഇല്ലാത്ത SameSite=None, സബ്ഡൊമെയ്‌നിൽ __Host- കുക്കി, കഴിഞ്ഞ കാലഹരണം: നിയമം ഫീൽഡിനടുത്തുതന്നെ വിശദീകരിക്കും.
• JWT പോലുള്ള നീണ്ട മൂല്യങ്ങൾ ലേഔട്ട് ഒരിക്കലും തകർക്കില്ല; ഏത് മൂല്യവും ഒരു കീ കൊണ്ട് പകർത്താം.
• പ്രധാനപ്പെട്ട കുക്കികൾ സംരക്ഷിക്കുക, അപ്പോൾ ബൾക്ക് ഡിലീറ്റ്, ഇമ്പോർട്ട്, സെറ്റ് പുനഃസ്ഥാപനം എന്നിവ അവയെ തൊടില്ല.
