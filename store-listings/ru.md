CookieDesk это редактор куки (cookie editor) для разработчиков, тестировщиков и всех, кто хочет увидеть, что сайт хранит в браузере. Просмотр куки, изменение, добавление и удаление куки, поиск по ним: во всплывающем окне или в боковой панели, на ваш выбор.

ЧЕМ ОТЛИЧАЕТСЯ

• Редактор куки с разделами (partitioned). Chrome скрывает куки с разделами (CHIPS) от инструментов, которые о них не просят, поэтому другие редакторы куки молча показывают неполный список. CookieDesk показывает их рядом с обычными, и у каждых указан раздел.
• Отмена любого изменения. Правки, удаления, импорт и восстановление наборов сначала записываются в журнал отмены и затем проверяются. Если Chrome отклоняет изменение, всё откатывается, и вы узнаёте причину. Один щелчок возвращает куки точно в прежнее состояние в течение 10 минут; если копию для отмены сохранить не удаётся (это бывает редко), CookieDesk спросит, продолжать ли.
• Редактор куки без рекламы, слежки и сетевых запросов. Открытый исходный код: можно проверить каждую строку.
• Разрешение для каждого сайта. При установке нет запроса «Чтение и изменение всех ваших данных на всех сайтах». Вы разрешаете CookieDesk по одному сайту, видите все разрешённые сайты и убираете любой одним щелчком.

ПРОСМОТР КУКИ

• Просмотр куки (cookie viewer) для всех куки текущего сайта: имя, значение, домен, путь и срок действия, с метками HttpOnly, Secure, SameSite, сеансовых куки и куки с разделами.
• Куки HttpOnly чётко помечены как «недоступные JavaScript на странице».
• Настоящий поиск: фильтр по имени, значению или домену прямо при вводе, даже если куки сотни.
• Живой просмотр: видно, какие куки сайт задаёт или меняет, пока вы с ним работаете.
• «Что делают эти куки»: каждый флаг объяснён простыми словами, включая то, является ли значение токеном JSON Web Token и когда этот токен истекает.

ИЗМЕНЕНИЕ КУКИ

• Изменение куки HttpOnly и всех остальных полей: имя, значение, домен, путь, срок действия, Secure, HttpOnly, SameSite и раздел.
• Ошибки ловятся до того, как их увидит Chrome. SameSite=None без Secure, куки __Host- на поддомене, срок действия в прошлом: правило объясняется рядом с полем.
• Длинные значения вроде JWT не ломают вёрстку; скопировать любое значение можно одной клавишей.
• Защитите важные куки, чтобы массовое удаление, импорт и восстановление набора их не затрагивали.

УДАЛЕНИЕ КУКИ

• Удалите одни куки или все, которые показывает поиск, после списка того, что именно будет удалено. Отмена доступна 10 минут.

МЕНЕДЖЕР КУКИ ДЛЯ РЕАЛЬНОЙ РАБОТЫ

• Наборы куки: сохраните куки сайта как файл с именем (например, «вход под админом») и восстановите позже. CookieDesk показывает, что изменится, прежде чем что-либо сделать, и сам копий не хранит.
• Сравнение: посмотрите, что изменил вход на сайт (какие куки добавились, исчезли или изменились), между сохранённым набором и текущим состоянием или между двумя наборами.
• Копирование куки между обычным окном и окном инкогнито (после включения для CookieDesk параметра «Разрешить использование в режиме инкогнито»).
• Импорт и экспорт в JSON или Netscape cookies.txt, а также копирование куки как сниппета document.cookie. При экспорте вас предупреждают, что в файле действующие сеансовые куки и обращаться с ним нужно как с паролем.
• Управление с клавиатуры: / для поиска, стрелки для перемещения, Enter для изменения, c для копирования, p для защиты, Del для удаления, Ctrl+Z для отмены, ? для полного списка.

КОНФИДЕНЦИАЛЬНОСТЬ

CookieDesk ничего не собирает и никуда ничего не отправляет. Никакой аналитики, учётных записей, синхронизации и удалённого кода. CookieDesk не хранит значения куки на диске: копии для отмены лежат в памяти и пропадают при закрытии Chrome. (Куки, которые вы копируете в обычное хранилище, как и любые другие куки там, сохраняет Chrome.) Настройки и счётчики использования хранятся локально. Исходный код открыт по лицензии MIT.

Доступно на 51 языке.
