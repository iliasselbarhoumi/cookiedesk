CookieDesk คือตัวแก้ไขคุกกี้สำหรับนักพัฒนา ผู้ทดสอบ และทุกคนที่อยากรู้ว่าเว็บไซต์เก็บอะไรไว้บ้าง ดูคุกกี้ แก้ไขคุกกี้ เพิ่มและลบคุกกี้ และค้นหาคุกกี้ได้ในป๊อปอัปหรือแผงด้านข้าง คุณเลือกเอง

จุดเด่น

• ตัวแก้ไขคุกกี้แบบแบ่งพาร์ทิชัน Chrome ซ่อนคุกกี้แบบแบ่งพาร์ทิชัน (CHIPS) จากเครื่องมือที่ไม่ได้ขอ ตัวแก้ไขคุกกี้อื่นจึงแสดงรายการที่ไม่ครบโดยไม่บอกใคร CookieDesk แสดงคุกกี้เหล่านี้ไว้ข้างคุกกี้ปกติ พร้อมระบุพาร์ทิชันของแต่ละรายการ
• เลิกทำได้ทุกการเปลี่ยนแปลง การแก้ไข การลบ การนำเข้า และการกู้คืนชุดจะถูกเขียนลงบันทึกการเลิกทำก่อน แล้วตรวจสอบภายหลัง หาก Chrome ปฏิเสธการเปลี่ยนแปลง ทุกอย่างจะย้อนกลับและบอกเหตุผล คลิกเดียวก็คืนคุกกี้ให้เหมือนเดิมทุกประการได้ภายใน 10 นาที ในกรณีที่หายากซึ่งเก็บสำเนาสำหรับเลิกทำไม่ได้ CookieDesk จะถามก่อนดำเนินการต่อ
• ตัวแก้ไขคุกกี้ที่ไม่มีโฆษณา ไม่ติดตาม และไม่มีคำขอเครือข่าย เป็นโอเพนซอร์ส คุณตรวจสอบได้ทุกบรรทัด
• ขออนุญาตทีละเว็บไซต์ ตอนติดตั้งจะไม่มีข้อความ "อ่านและเปลี่ยนแปลงข้อมูลทั้งหมดของคุณในเว็บไซต์ทั้งหมด" คุณอนุญาตให้ CookieDesk ทีละเว็บไซต์ ดูเว็บไซต์ที่อนุญาตไว้ทั้งหมด และนำออกได้ด้วยคลิกเดียว

ดูคุกกี้

• ตัวดูคุกกี้ที่แสดงทุกคุกกี้ของเว็บไซต์ปัจจุบัน: ชื่อ ค่า โดเมน เส้นทาง และวันหมดอายุ พร้อมป้ายสำหรับคุกกี้ HttpOnly, Secure, SameSite, เซสชัน และแบบแบ่งพาร์ทิชัน
• คุกกี้ HttpOnly มีป้ายชัดเจนว่า "JavaScript ของหน้าเว็บมองไม่เห็น"
• ค้นหาได้จริง: กรองตามชื่อ ค่า หรือโดเมนทันทีที่พิมพ์ แม้มีคุกกี้เป็นร้อยรายการ
• มุมมองสด: ดูว่าเว็บไซต์ตั้งหรือเปลี่ยนคุกกี้ตัวไหนขณะที่คุณใช้งาน
• "คุกกี้นี้ทำอะไร": อธิบายทุกแฟล็กด้วยภาษาง่าย ๆ รวมถึงว่าค่านั้นเป็น JSON Web Token หรือไม่ และโทเค็นนั้นหมดอายุเมื่อใด

แก้ไขคุกกี้

• แก้ไขคุกกี้ HttpOnly และทุกช่อง: ชื่อ ค่า โดเมน เส้นทาง วันหมดอายุ Secure, HttpOnly, SameSite และพาร์ทิชัน
• จับข้อผิดพลาดได้ก่อนที่ Chrome จะเห็น SameSite=None ที่ไม่มี Secure คุกกี้ __Host- บนโดเมนย่อย วันหมดอายุในอดีต: กฎจะอธิบายไว้ข้างช่องนั้น
• ค่ายาว ๆ อย่าง JWT ไม่ทำให้เลย์เอาต์พัง คัดลอกค่าใดก็ได้ด้วยปุ่มเดียว
• ป้องกันคุกกี้สำคัญ เพื่อให้การลบจำนวนมาก การนำเข้า และการกู้คืนชุดไม่แตะต้อง

ลบคุกกี้

• ลบคุกกี้หนึ่งรายการ หรือทุกรายการที่ผลการค้นหาแสดง หลังดูรายการว่าอะไรจะถูกลบ เลิกทำได้ภายใน 10 นาที

ตัวจัดการคุกกี้สำหรับงานจริง

• ชุดคุกกี้: บันทึกคุกกี้ของเว็บไซต์เป็นไฟล์ที่ตั้งชื่อ (เช่น "ลงชื่อเข้าใช้เป็นผู้ดูแล") แล้วกู้คืนภายหลัง CookieDesk แสดงสิ่งที่จะเปลี่ยนก่อนลงมือ และไม่เก็บสำเนาไว้เอง
• เปรียบเทียบ: ดูว่าการลงชื่อเข้าใช้ทำอะไร (คุกกี้ตัวไหนเพิ่ม ลบ หรือเปลี่ยน) ระหว่างชุดที่บันทึกไว้กับปัจจุบัน หรือระหว่างสองชุด
• คัดลอกคุกกี้ระหว่างหน้าต่างปกติกับหน้าต่างไม่ระบุตัวตน (หลังเปิด "อนุญาตในโหมดไม่ระบุตัวตน" ให้ CookieDesk)
• นำเข้าและส่งออก JSON หรือ Netscape cookies.txt หรือคัดลอกคุกกี้เป็นสนิปเป็ต document.cookie การส่งออกจะเตือนว่าไฟล์มีคุกกี้เซสชันที่ใช้งานอยู่และควรปฏิบัติเหมือนรหัสผ่าน
• ใช้แป้นพิมพ์เป็นหลัก: / ค้นหา ลูกศรเลื่อน Enter แก้ไข c คัดลอก p ป้องกัน Del ลบ Ctrl+Z เลิกทำ ? ดูรายการทั้งหมด
